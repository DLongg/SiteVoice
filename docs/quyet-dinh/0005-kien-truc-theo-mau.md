# 0005. Kiến trúc theo Mẫu (Template)

Trạng thái: chấp nhận

## Quyết định
Mỗi loại tài liệu là một Mẫu gồm: `schema.json` (trường + giới hạn), `prompt.md` (tổng hợp), `doc-mau.md` (placeholder + link Doc mẫu), cùng quy tắc thời gian. Code lõi không chứa nội dung riêng của nhật ký công trường.

## Tiêu chí kiểm chứng
Thêm Mẫu thứ hai (báo cáo tuần) mà không sửa code lõi.

## Hệ quả
Mẫu được đóng gói vào assets của app và kiểm tra schema khi nạp.
