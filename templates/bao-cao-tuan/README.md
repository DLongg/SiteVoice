# Mẫu: Báo cáo tuần (kế hoạch, chưa làm)

Mục đích: kiểm chứng lõi Mẫu đủ tổng quát.

Ý tưởng:
- Nguồn dữ liệu: các DailyReport đã duyệt trong tuần (không tổng hợp lại từ ghi chú thô).
- Trường dự kiến: tiến độ so với kế hoạch, hạng mục hoàn thành, vấn đề tồn đọng, đề xuất, kế hoạch tuần tới, thống kê (số ngày mưa, tổng công nhân).
- Cần: `schema.json`, `prompt.md`, `doc-mau.md` theo cùng khuôn với `nhat-ky-cong-truong/`.
