# Mẫu (Template)

Mỗi thư mục con là một loại tài liệu. Một Mẫu gồm:
1. `schema.json`: trường nhập tay, mục ghi chú, trường tổng hợp và giới hạn ký tự/số dòng.
2. `prompt.md`: prompt tổng hợp.
3. `doc-mau.md`: link Google Doc mẫu và bảng placeholder.

Thêm loại tài liệu mới = thêm một thư mục theo khuôn trên, không sửa code lõi.
Mẫu hiện có: `nhat-ky-cong-truong` (hoàn chỉnh), `bao-cao-tuan` và `nhat-ky-ca-nhan` (khung).
